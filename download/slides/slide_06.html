FleetVision AI | Zeroth Review 06
This slide presents the system architecture and technology stack powering FleetVision AI. The architecture follows a layered approach with clear separation of concerns. At the top, the React Frontend provides the user interface built with Tailwind CSS for styling, Chart.js for data visualizations, and Leaflet for interactive map displays. Users interact with dashboards, reports, and management interfaces through this layer. All communication passes through the REST API layer secured by Spring Security with JWT authentication. Token-based auth ensures secure access, while role-based access control differentiates between admin, manager, and driver roles. The Spring Boot Backend forms the core application layer, handling business logic, data processing, and API controllers. It orchestrates requests between the frontend, database, and AI services. At the data layer, we have three components: MySQL Database managed through Prisma ORM for structured fleet data, Python AI services running on FastAPI for all seven machine learning predictions, and External APIs including Maps for routing and Weather data for risk analysis. The technology stack spans four categories. Frontend uses React.js with Tailwind CSS and Chart.js for rich visualizations. Backend runs on Spring Boot with Spring Security for JWT auth and Spring Data JPA for database operations. The AI/ML layer uses Python with FastAPI, Scikit-learn for classification models, XGBoost for regression predictions, and Pandas and NumPy for data processing. DevOps tooling includes Docker for containerization, Git and GitHub for version control, Postman for API testing, and Maven for Java dependency management.
